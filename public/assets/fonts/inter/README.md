# Inter Font Assets (Self-hosted)

Lege die folgenden Dateien in dieses Verzeichnis, um Inter lokal bereitzustellen:

- `inter-latin-400.woff2`
- `inter-latin-500.woff2`
- `inter-latin-600.woff2`
- `inter-latin-700.woff2`
- `inter-latin-800.woff2`

Empfohlene Quelle: offizielles Inter-Release oder eigener, rechtssicherer Font-Export.

Hinweise:

- Nur Dateien verwenden, deren Lizenz und Herkunft geprüft sind.
- Dateinamen und Pfad müssen exakt den Angaben in `styles/globals.css` entsprechen.
- Optional können zusätzliche Subsets/Gewichte ergänzt werden.
- Optional können zusätzlich `.woff`-Dateien abgelegt und in `@font-face` ergänzt werden.

Nach dem Ablegen der Dateien werden keine externen Requests zu `fonts.googleapis.com` oder `fonts.gstatic.com` benötigt.
